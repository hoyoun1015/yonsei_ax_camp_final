## 한 문장

자연어로 제시된 분자 구조·안정성 가설을 AI 에이전트가 해석하고, 필요한 계산화학 실험을
스스로 설계·실행·분석하며, 결과가 불충분하면 후속 계산까지 결정하여 최종적으로 가설을
지지·기각·판단보류하는 **자율 계산화학 연구 에이전트**를 개발하고 검증한다.

연구 질문은 RQ1(가설 해석) · RQ2(실험 설계) · RQ3(적응적 추론) · RQ4(결론과 과대해석 억제)
넷이다. 이 중 **RQ3와 RQ4를 사람 판단이나 LLM 판정 없이 재는 방법**이 v3에서 새로 더한 것이며,
그것이 방법오차 τ 사다리다 (기획안 §3).
