## 2026-08-08 — 기획안 v3 검토 결과 반영 (실측 기반)

적대적 검토 워크플로가 프로세스 종료로 중단되어 결과를 얻지 못했다.
대신 가장 위험한 두 지적을 **직접 데이터로 확인**했다.

### ① pseudo-replication — 확인됨, 설계 변경

GMTKN55를 직접 클론(170 MB)하고 각 구조의 `struc.xyz`에서 분자식을 뽑아
서브셋별 고유 화학종 수를 셌다.

- **MCONF 52구조 = 화학종 1개** (멜라토닌). BUT14DIOL 65구조 = 1개. UPU23 24구조 = 1개.
- 초안은 "MCONF에서만 1,275쌍"을 장점으로 적었으나, 그 100과제의 실효 표본은 한 자릿수다.
- **해결**: 추론 단위를 과제가 아닌 **고유 화학종**으로 고정.
  소 ΔE는 Amino20x4(19종)·ICONF(10종) 중심, 대 ΔE는 ISO34(28종)·ISOL24(24종) 중심.
  MCONF·BUT14DIOL·UPU23은 독립 단위에서 제외하고 내부 분산 추정용으로 강등.
- **부수 효과**: 서브셋을 6개 → 11개로 넓히면서 가용 반응 159 → **363개**,
  독립 화학종 **약 92종** 확보.

### ② L3 DFT 실현성 — 확인됨, 도구 확정

conda-forge osx-arm64 빌드 확인: **Psi4 154빌드(1.9.1)**, **xtb 6.7.1**, **CREST 3.0.2**.
L3는 Psi4 **B3LYP-D3(BJ)/def2-TZVP** 단일점으로 확정.
r²SCAN-3c는 gCP 보정이 Psi4에 없어 제외.

원자수 실측: 중앙값 ~28, 최대 81(ISOL24). L3 대상 332구조, 추정 25~45시간.
**1일차에 ISOL24 최대 구조 3개로 시간을 먼저 실측**하고 초과 시 basis 축소 또는
밴드 A 공급원을 ISO34로 이동.

### ③ 내부 모순 1건 (앞서 자체 발견) — 수정 완료

§3은 `τ₃ < |ΔE_ref| ≤ τ₂`를 "L3로 판정 가능"으로, §4.2는 같은 구간을 "정답 ABSTAIN"으로
정의해 충돌했다. 밴드를 A/B/C/D 넷으로 나누고 **정답을 에이전트가 사용한 수준 M의 함수**로
재정의(§3.1). 게이트도 G3(밴드 C 화학종 25종 이상, 15종 미만이면 폐기)를 최우선으로 재배치.

### 미해결

- 호출 예산 추정 ~3,180으로 3,000 초과 → 축소 순서 사전 규정함 (밴드 C는 마지막)

## 2026-08-08 — 연구 방향 확정

**결정.** 주제는 **방법오차 기반 abstention 평가**. Virtual Computational Chemistry Lab은
그 질문을 던지기 위한 시스템이지 그 자체가 기여가 아니다.

**근거.** 8개 후보(단백질 안정성, pKa, 반응 최적화, NMR, 용매화, host-guest,
효소 기전 감사, 구조-열역학)를 자원 실재성·선점·자명한 기준선 기준으로 검증한 결과
이것만 살아남았다. **유일하게 강한 자명한 기준선이 적이 아닌 설계**다 —
규칙 기반 abstention이 이겨도 그게 발견이 된다.
상세는 `docs/검증된_사실.md` §7.

## 2026-08-08 — 사전 확정 사항 (기획안 v3 반영 대상)

기획안 v2에서 다음을 수정하기로 합의. 확정본에 반영되어야 한다.

1. **ABSTAIN 라벨을 GMTKN55 참조값에서 기계적으로 유도** (`|참조 Δ| ≤ τ_subset`).
   손으로 "작게 설정"하는 방식 폐기 — 평가 대상 도구로 라벨을 만드는 순환논증.
2. **τ = 서브셋별 GFN2-xTB MAE 실측.** 파이프라인 재현성 아님.
3. **관측량은 ΔE.** 참조값과 일치시킴. 열역학 보정을 넣으려면 오차를 별도 측정해 합산.
4. **과제 수 12~20 → 100 이상.** 라벨이 자동 유도되므로 가능. 계산은 공짜.
5. **Fixed 기준선을 최강 파이프라인으로** + **규칙 기반 abstention 기준선 추가**.
6. **기여 순서 변경** — abstention을 1번으로. 파이프라인 구현은 기여에서 제외
   (ChemGraph·El Agente Q 선점).
7. **효율성 주장(H4·Metric 3) 삭제 또는 재정의.** 잡당 0.3초에서 계산 횟수 절감은
   과학적 통화가 아니다. DFT escalation을 넣는 경우에만 유효.
