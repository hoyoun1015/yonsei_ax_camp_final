# 선행연구 조사 및 계보

**조사일 2026-08-08.** 백지에서 새로 검색했다. 이전 조사 결과는 참조하지 않았고,
앵커를 미리 정해두고 맞춰 넣지 않았다. 기획안이 실제로 주장하는 것에서 출발해
역으로 계보를 찾았다.

---

# 0. 기획안이 주장하는 것 (탐색의 출발점)

주제 진술을 처음 보는 것으로 읽으면 주장이 셋으로 분해된다.

1. **AI 에이전트가 자연어 가설을 받아 실제 양자화학 계산을 실행하고 결론을 낸다.**
   → 갈래 A · 시스템 계보
2. **그 결론이 잘한 것인지 채점해야 한다.**
   → 갈래 B · 평가 계보
3. **특히 "모를 때 멈추는가"(RQ4)와 "언제 더 계산하는가"(RQ3)를 채점해야 한다.**
   → 갈래 C · 판단보류 계보 / 갈래 D · 인식적 정직성 계보
4. **그 채점의 기준선은 물리에서 온다.**
   → 갈래 E · 방법오차·불확실성 정량화 계보

# 2. 갈래 B — 그 시스템들을 무엇으로 채점하는가

여기가 본 연구가 파고들 자리다. **채점 방식만 뽑아 보면 전부 같은 계열이다.**

| 논문 | 채점 방식 | 재는 것 |
|---|---|---|
| ChemCrow | LLM 판정 + 전문가 평가 | 태스크 성공 여부 |
| El Agente Q | **인간 전문가 rubric 100점**, 평가자 5명 | 태스크 성공 여부 |
| ChemGraph | 13태스크 260인스턴스에서 **최종 수치 정답 일치** | 태스크 성공 여부 |
| **MDGym** (arXiv 2605.08941) | LAMMPS·GROMACS 169개 MD 과제, 3단계 난이도. Claude Code·Codex·OpenHands × 4 LLM | **실행 성공률.** 최강 에이전트가 easy 21%, 상위 난이도 <10% |
| **MDArena** (arXiv 2608.02642) | 현실적 MD 워크플로에서 코딩 에이전트 평가 | 같음 |
| **ScienceAgentBench** (arXiv 2410.05080) | 102 태스크, 계산화학 포함 | 코드 산출물 정답 대조 |
| **ASTABench** (ICLR 2026) | 과학 에이전트 종합 | 태스크 성공 여부 |

## MDGym의 실패 모드가 결정적이다

MDGym이 관찰한 특징적 실패는 이것이다 —
**"에이전트가 시뮬레이션 기계를 성공적으로 호출하지만, 물리적으로 불안정한 구조를
만들거나, 실제 계산을 실행하지 않고 수치를 지어내거나, 반복하지 않고 과제를 포기한다."**

즉 **도구를 돌리는 능력과 그 결과를 해석하는 능력은 별개**라는 것이
이 갈래에서 실측으로 확인됐다. 그런데 MDGym조차 채점은 **"과제를 풀었는가"**다.
"풀 수 없는 문제였는데 풀었다고 했는가"는 재지 않는다.

**→ 갈래 B 전체가 outcome-only다.**

# 3. 갈래 C — 판단보류 (임계값이 전부 모델 내부에서 나온다)

| 논문 | 임계값의 출처 |
|---|---|
| **AbstentionBench** (arXiv 2506.09038) | 질문의 모호성·답 가능성 |
| **Know Your Limits: A Survey of Abstention in LLMs** (2025) | 서베이 — 분류 체계 |
| **Uncertainty-Aware Abstention with Provable Alignment Guarantees** (arXiv 2607.04430) | 신뢰구간 기반 보정(CIC). 보정집합에서 임계값 조건부 오류율 추정 |
| **Two Axes of LLM Abstention** (arXiv 2607.08456) | 답 정확성 / 질문 답가능성 2축, 두 임계값 정책 |
| **Knowing When Not to Answer: Abstention-Aware Scientific Reasoning** (arXiv 2602.14189) | 모델 confidence. SciFact/PubMedQA — **텍스트 기반, 계산 없음** |
| **AgentAbstain** (arXiv 2607.10059) | 263 쌍 과제 / 42 실행환경 / 17 프론티어 LLM. 8종 abstention 시나리오 분류. **최고 모델도 60% 미만** |
| **What Benchmarks Don't Measure** (arXiv 2606.02965) | ★ **compliance bias** — RLHF가 "진행하는 것"을 기본 보상으로 만들고, 벤치마크가 "원칙 있는 멈춤"과 "조용한 실패"를 구분하지 못한다. specification/verification/authority 3-gap 분류 |
| **Act or Escalate?** (arXiv 2604.08588) | ★ 행동 vs 에스컬레이션을 **비용 하의 결정**으로 모델링. 5개 도메인. **모델마다 암묵적 임계값이 크게 다르고 자기추정이 miscalibrated** |

## 판정 — 여기에 빈틈이 있다

이 갈래는 두 가지를 이미 확립했다.

1. **에이전트는 멈춰야 할 때 멈추지 않는다** (AgentAbstain <60%, compliance bias)
2. **에스컬레이션 임계값은 모델마다 제멋대로이고 보정돼 있지 않다** (Act or Escalate)

그런데 **임계값의 출처가 전부 모델 내부다** — confidence, entropy, conformal calibration,
질문 모호성, 비용비. **물리 계측기의 벤치마크된 오차에서 임계값을 유도한 사례를 찾지 못했다.**

직접 검색으로 확인:
`abstention threshold physical method error benchmark MAE` → 해당 없음.
반환된 것은 embodied QA, 의료영상, LLM entropy 계열뿐이다.

**이것이 본 연구 기여 3의 자리다.**

# 4. 갈래 D — 인식적 정직성 (앵커가 여기 있다)

| 논문 | 관찰 | 계측기 |
|---|---|---|
| **Position: Correct Answer, Wrong Mechanism** (arXiv 2606.23175, 2026-06) | Geant4 입자물리. 28 에피소드 중 primary 4/20, cross-model 3/8에서 **CAWM** — 맞아 보이는 결과를 틀린 추론으로 도달. 에이전트가 **한 번도 시험하지 않은 영역으로 결론을 확장**하고, 자기 출력의 수치와 모순되는 설명을 지어낸다 | **없음.** position paper, 정성 관찰 |
| ★ **AI scientists produce results without reasoning scientifically** (arXiv 2604.18805, 2026-04) | **8개 도메인(벤치마크 Corral) · 25,000+ 에이전트 실행.** 베이스 모델이 성능·행동의 41.4% 설명분산, 스캐폴드는 1.5%. **증거가 68%의 트레이스에서 무시된다. 반증 기반 신념 수정은 26%에서만 일어난다** | ★ **Claude Sonnet 4.5 2단계 주석 파이프라인** (본문 §4.8·H.1 직접 확인). 인간 전문가 2인이 626 트레이스로 검증 — 인간–인간 92.6%, 인간–LLM 95.7% |
| **Workflow Closure Is Not Scientific Closure** (arXiv 2605.26200) | 100+ 논문 서베이 + 21개 시스템 감사. **objective collapse / validation collapse / acceptance collapse** 3종 붕괴. "자율 실행은 하되 인식적 통제는 비자율이어야 한다" | 없음 |
| **Agentic AI Scientists Are Not Built For Autonomous Discovery** (arXiv 2605.08956) | 같은 방향의 포지션 | 없음 |
| **StatefulDiscovery** (arXiv 2606.11851) | ★ **overinterpretation을 명시적으로 문제로 정의** — "주장이 그것을 뒷받침하는 분석의 증거 범위를 초과하는 것". 탐색 궤적과 주장 상태를 결합해 **claim adjudication** | 판정이 **LLM/모델 기반 adjudication** |

## 앵커 — arXiv 2604.18805 (본문 109p 직접 확인, 2026-08-08)

**앵커로 확정한다.** 네 가지 이유다.

1. **주장이 우리 RQ4와 정확히 같다.** "증거가 무시된다"는 곧 "자기 데이터가 지지하지 않는
   결론을 낸다"이고, 기획안 §3.1의 "방향이 맞았으니 정답이 아니다"와 같은 명제다.
2. **규모와 정량성이 압도적이다.** 25,000 실행 · 8도메인 · IRT 기반 분산분해까지 있다.
   2606.23175(28 에피소드 position paper)보다 인용 가치가 높고, 저자 그룹(Jablonka,
   Krishnan)이 화학 AI 쪽이라 도메인 접점도 가깝다.
3. ★ **판정 기준이 LLM이다.** 본문 §4.8 및 H.1에서 확인:
   **Stage 1에서 Claude Sonnet 4.5가 메시지 단위로 인식적 조작(hypothesis/test/evidence/
   judgment/commitment)을 라벨링하고, Stage 2에서 같은 모델이 엣지를 만든다.**
   인간 전문가 2인이 626 트레이스로 검증했고 인간–LLM 일치 95.7%로 보고했지만,
   **파이프라인 본체는 LLM 판정자다.**
4. **저자들의 결론이 우리 자리를 지목한다** —
   *"Outcome-based evaluation cannot detect these failures, and scaffold engineering
   alone cannot repair them."*

**즉 앵커는 "결과 기반 평가로는 안 된다"고 말하고, 대안으로 LLM 주석을 썼다.
우리는 같은 자리에 물리 임계값을 넣는다 — 판정에 모델이 한 번도 개입하지 않는다.**

### 본문에서 확인한 8개 도메인 (벤치마크 이름: Corral)

AFM 실험 실행(실제 현미경 in the loop) · 흡착 표면 구성(pymatgen) ·
**분자 시뮬레이션(LAMMPS)** · ML 물성 예측(Materials Project) · 회로 추론 ·
역합성 계획 · 분광 구조 규명 · 무기 정성분석(열역학 평형 엔진)

**양자화학·conformer 상대에너지는 없다.** 우리 도메인은 인접하지만 비어 있다.

### 우리 설계에 직접 걸리는 수치

- 주석 대상 부분집합에서 **evidence non-uptake가 Claude Sonnet 4.5·GPT-4o 모두 88%**,
  refutation-driven belief revision은 각각 4%·1%. 전체 평균 68%/26%보다 훨씬 나쁘다.
- **워크플로 도메인의 evidence non-uptake가 82%**로 가장 높다.
  우리 과제는 워크플로 성격이 강하므로 과대해석률이 높게 나올 것으로 예상해야 한다.
- 앵커 관련연구 첫 문장: *"Existing benchmarks for scientific agents primarily score
  outcomes."* — 본 문서 §2의 판정과 일치한다.

### 왜 2606.23175를 앵커로 두지 않는가

같은 명제를 더 선명하게 말하지만 position paper이고 28 에피소드다.
**보조 앵커**로 인용하되 주 앵커는 정량 논문으로 둔다.

### 왜 StatefulDiscovery를 앵커로 두지 않는가

overinterpretation을 정면으로 다루지만 **판정이 모델 기반 adjudication**이다.
우리는 그 판정을 물리로 대체한다 — 즉 **경쟁 상대이자 대비 대상**이지 앵커가 아니다.
논문에서 반드시 대비해야 할 가장 가까운 연구다.

## 중요 — 개념 자체는 새롭지 않다

계산화학에서 **"에너지차가 방법오차 안에 있으면 순위를 주장할 수 없다"는 인식은
이미 확립돼 있다.** UQ 리뷰가 통째로 그 주제이고, conformer 에너지차가 흔히
1~2 kcal/mol이며 이것이 방법오차 범위 안이라는 서술도 흔하다.

**따라서 신규성은 "우리가 방법오차의 중요성을 발견했다"가 아니다.**
그 인식을 **AI 에이전트 판단의 채점 기준으로 조작화하고, 에이전트가 그것을 지키는지
측정한 것**이 신규성이다. 논문에서 이 구분을 명시하지 않으면 계산화학 심사자가
"우리가 늘 알던 것 아닌가"로 반박한다.

# 6. 논리 전개 — 여덟 문장

1. **자연어 가설에서 양자화학 계산까지 자동으로 가는 에이전트는 이미 여럿 있다.**
   ChemCrow → El Agente Q → ChemGraph → FermiLink. 파이프라인은 확립됐다.
2. **그런데 이들의 평가는 전부 "해냈는가"다.** 인간 rubric(El Agente Q),
   수치 정답 일치(ChemGraph), 실행 성공률(MDGym).
3. **그리고 그 평가로는 잡히지 않는 실패가 실측됐다.** MDGym은 에이전트가
   계산을 실행하지 않고 수치를 지어내는 것을 관찰했고, arXiv 2604.18805는
   25,000 실행에서 **증거가 68%의 트레이스에서 무시된다**는 것을 보였다.
4. **앵커는 결론을 명확히 한다 — 결과 기반 평가로는 이 실패를 탐지할 수 없다.**
   그러나 무엇으로 대체할지, 무엇에 비추어 "증거를 무시했다"고 판정할지는 주지 않는다.
5. **판단보류 연구가 그 자리를 노리지만 임계값이 전부 모델 내부에서 나온다.**
   confidence·entropy·conformal·비용비. Act or Escalate는 그 임계값이
   모델마다 다르고 보정돼 있지 않음을 보였다.
6. **계산화학에는 모델 밖에 있는 기준이 이미 존재한다 — 방법오차다.**
   GMTKN55 참조값 대비 MAE로 측정되고, 방법을 바꾸면 변한다(g-xTB가 GFN2-xTB의 절반).
7. **따라서 τ는 계산 수준 M의 함수로 실측 가능하고, 이것이 두 개의 계측기를 만든다.**
   RQ4 — 자기 증거가 τ(M_used)보다 작은데 단정했는가(과대해석).
   RQ3 — |ΔE_ref|와 τ 사다리의 관계로 SUFFICIENT/ESCALATION/FUTILE이 기계적으로 결정된다.
8. **그 결과 에이전트의 인식적 정직성이 사람도 LLM도 없이 채점된다.**
   앵커가 "결과 기반으로는 안 된다"고 한 자리에 결정론적 계측기가 들어간다.

# 8. 이번 조사에서 새로 드러난 위험

1. **🔴 이름 충돌 — VirtualLab_CC (2026).** "Virtual Lab" 계열 이름을 쓸 수 없다.
2. **🟠 StatefulDiscovery(2606.11851)가 가장 가까운 경쟁이다.** overinterpretation을
   같은 이름으로 정의한다. 차별점은 판정 방식(모델 adjudication vs 물리 임계값)뿐이므로
   본문에서 이 대비를 선명하게 세워야 한다.
3. **🟠 MDGym·MDArena가 "시뮬레이션 에이전트 벤치마크" 자리를 빠르게 채우고 있다.**
   우리가 "또 하나의 시뮬레이션 벤치마크"로 읽히지 않으려면 기여 2·3(계측기)을
   초록 첫 문단에 놓아야 한다.
4. **🟡 앵커 2604.18805가 "스캐폴드는 1.5%만 설명한다"고 보고했다.** 이는 우리 F/A/V
   조건 비교(스캐폴드 차이)가 **널로 나올 가능성이 높다는 사전 경고**다.
   기획안 §13의 "R0가 이긴다"가 유력 시나리오라는 예상과 일치한다. 오히려
   앵커의 예측을 우리 도메인에서 재확인하는 결과가 되므로 논문은 성립한다.
