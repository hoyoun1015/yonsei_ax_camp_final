# 주장 강도 대응표 (Claim-Language Matrix) — 본문 아님

**작성 2026-08-20 · 어떤 증거에 어떤 표현까지 허용되는지 정한다**

`paper_logic/paper_fol_10.md` 의 단계별 Boundary 가 정본이고, 이 문서는 **집필 중 문장
하나를 쓸 때 바로 참조하는 표**다. 충돌하면 Paper-FOL 이 이긴다.

**쓰는 법** — 문장을 쓰기 전에 «이 문장이 기대는 증거가 아래 열 중 어디인가»를 먼저 정한다.
등급이 정해지면 동사와 완충어가 자동으로 결정된다.

---

## 1. 등급표

### ① 직접 측정값 — 우리가 실제로 센 수

| | |
|---|---|
| 허용 동사 | …이었다 · …였다 · …을 냈다 · 수행하였다 · 측정하였다 |
| 문장 강도 | **완충 없이 단정.** 「약」·「대체로」를 붙이지 않는다 |
| 필수 qualifier | 분모를 함께 적는다(74/92, 21/30) |
| 금지 | 이 문장 안에서 의미를 부여하는 것 |
| 우리 예 | *V 는 92과제 중 74과제에서 근거가 충분한 결론을 냈다* · *Sonnet V 는 21/30 이었다* · *L3 실행 횟수는 45회와 101회였다* |

### ② 사전에 정한 지표 — 실행 전에 지표가 고정된 것

| | |
|---|---|
| 대상 | **과대해석**(주 지표) · 근거가 충분한 결론 · 과도한 신중 · 참조방향 정확 |
| 허용 동사 | ①과 같음 + 「사전에 정한 지표인 …에서는」 |
| 필수 qualifier | **지표가 실행 전에 정해졌다는 것과 검정이 사후라는 것을 구분해서 적는다.** 표 S1 의 세 등급 표기를 그대로 따른다 |
| 금지 | 「사전등록된 검정」 — **검정 목록은 실행 전에 고정되지 않았다** · 「사전에 정한 것은 …뿐」 같은 단순화 |
| 우리 예 | *사전에 정한 주 지표인 과대해석에서는 두 조건이 갈리지 않았다* |

### ③ 사전에 정한 비교축 — V 대 V−τ

| | |
|---|---|
| 허용 동사 | 비교하였다 · 갈렸다 · 달랐다 |
| 문장 강도 | 비교축이 사전에 정해졌다는 점은 **단정 가능** |
| 필수 qualifier | 비교축은 사전, **검정은 사후** |
| 우리 예 | *주 대비는 실행 전에 V 와 V−τ 로 정해져 있었다* · *Band C 부분집합에 대한 V 대 V−τ 비교축도 실행 전에 지정돼 있었다(표 S1)* |

### ④ 결과를 본 뒤 수행한 통계 검정 (post-hoc)

| | |
|---|---|
| 대상 | **N=92 의 정확 McNemar 8건 전부** |
| 허용 동사 | 검정하였다 · 불일치는 …였다 · p 는 …였다 |
| 문장 강도 | 수치는 단정, **해석은 한 단계 낮춘다** |
| 필수 qualifier | ⚠️ **「결과를 본 뒤 수행한 분석이다」** · **「다중비교 보정을 하지 않았다」** — 결과 절에 최소 한 번, 표 S1 각주에 한 번 |
| 금지 | 「사전등록된 검정에서」 · 보정 없이 여러 p 를 나열하고 종합 판정하기 |
| 우리 예 | *같은 92과제에 대한 짝지은 정확 McNemar 검정에서 불일치는 21:1 이었다(p = 1.1×10⁻⁵). 이 검정은 결과를 본 뒤 추가한 분석이다* |

### ⑤ 기술 통계 (descriptive)

| | |
|---|---|
| 대상 | 오류 분해 · 라운드 분포 · Band 별 수 · L0 probe · Band C(n=8, 보조 검증) |
| 허용 동사 | …였다 · 나타났다 |
| 문장 강도 | 수치만. **비교 주장으로 확장하지 않는다** |
| 필수 qualifier | 「검정하지 않았다」 |
| 금지 | 「더 낫다」·「경향이 있다」 |
| 우리 예 | *Band C 에서 sonnet V 는 7/8, R0 는 3/8 이었다. 검정하지 않았다* |

### ⑥ 탐색적 분석 (exploratory)

| | |
|---|---|
| 대상 | 오류 분해 2×2 · τ 제거 시 경로 B 증가 · Band A 의 V−τ < R0 |
| 허용 동사 | 관측되었다 · …로 보인다(처방 아님) |
| 필수 qualifier | **「탐색적 분석이다」**(S3 각주 문구와 같은 수준) |
| 금지 | 확증 결과와 같은 문단에 완충 없이 나열하기 |

### ⑦ 인과 ablation — 같은 A 에서 한 구성요소만 제거

| | |
|---|---|
| 대상 | V 대 V−τ |
| 허용 동사 | **바꾸었다 · 달라졌다**(인과어 허용) |
| 문장 강도 | 이 도메인·이 벤치마크 안에서 인과 귀속 가능 |
| 필수 qualifier | 검정은 사후 · 검출된 이득은 Band C 집중 · **단일 모델** |
| 금지 | 분산 설명력 표현(「X% 를 설명한다») · 앵커의 1.5% 와 병치 |
| 우리 예 | *방법 오차 정보만 제거하자 근거가 충분한 결론이 74에서 54로 줄었다* |

### ⑧ 다른 모델에서의 보조 증거 (cross-model)

| | |
|---|---|
| 대상 | sonnet 4.6 · V 단독 · N=30 |
| 허용 동사 | 충족하였다(방향 기준) · …이었다 |
| 필수 qualifier | **① 유의하지 않았다(p = 0.4531) ② V−τ 를 실행하지 않았다** — 둘 다 같은 문단에 |
| 금지 | ⛔ 「재현되었다」 단독 · 「τ 효과가 모델 간에 일반화된다」 · 모델 우열(p = 0.2188) |
| 우리 예 | 고정 문구(`writing_rules.md` §5-3) 그대로 |

### ⑨ null 결과 — 유의한 차이가 검출되지 않은 것

| | |
|---|---|
| 대상 | 과대해석 0 대 3(p = 0.25) · V−τ 대 R0(p = 0.86) · Band C 밖(p = 0.39) · sonnet 대 R0(p = 0.4531) |
| 허용 동사 | **갈리지 않았다 · 구분되지 않았다 · 검출되지 않았다** |
| 금지 | ⛔ **「차이가 없다」 · 「동등하다」 · 「같다」 · 「대등하다」** |
| 필수 qualifier | 표본·검정력의 한계를 한 번 밝힌다(예: 불일치 쌍이 몇 개뿐) |
| 서술 절차 | `writing_rules.md` §6-2 네 단계 — 앞쪽 배치 · 한 문장 · 변명 없음 · 다음 문단에서 실제로 갈린 축으로 |

### ⑩ 검증하지 않은 주장 — 실험이 없는 것

| | |
|---|---|
| 대상 | 경로 B 의 능력 · τ 효과의 모델 간 일반화 · 다른 관측량·수준으로의 확장 · 식별 난이도 |
| 허용 표현 | **「이 벤치마크에서 실질적으로 검증되지 않았다」 · 「이 데이터로는 답할 수 없다」** |
| 금지 | 어떤 형태의 성능 주장도. **반대 방향의 과잉 부정도 금지**(「그러므로 단순 fidelity router 다」) |

| 결과 | 등급 | 본문에서 반드시 |
|---|---|---|
| 과대해석 V 0 · V−τ 3 · **p = 0.25** | ② + ⑨ | **결과 절 앞쪽**에 배치. 「τ 가 과대해석을 줄였다」 금지 |
| 과도한 신중 0 대 20 (p = 1.9×10⁻⁶) | ④ | **사후 검정**임을 표시 |

| sonnet 21 대 R0 18 (p = 0.4531) | ⑧ + ⑨ | 방향 기준 충족 + 유의하지 않음 + V−τ 미실행 |
| τ 자체 | — | **확률적 신뢰구간이 아니다.** 참조값 대비 실측 평균 오차에서 유도한 **운용 임계값**이다 |

## 3. 자주 나오는 위반 패턴

| 쓰기 쉬운 문장 | 왜 안 되나 | 고친 형태 |
|---|---|---|
| τ 를 제공하자 판단 품질이 유의하게 향상되었다 | 주 지표는 널이고, 검정은 사후다 | 근거가 충분한 결론이 74에서 54로 줄었다(사후 검정 p = 1.1×10⁻⁵) |
| V−τ 는 규칙 기준선과 동등했다 | p > α 를 동등성으로 읽었다 | 규칙 기준선과 구분되지 않았다 |
| 효과는 Band C 에만 나타났다 | 비-C 는 검정력이 낮았을 뿐이다 | 검출된 이득은 Band C 에 집중되었다 |
| ALL_L3 대비 98.7% 성능을 30.6% 비용으로 | 비율 표현·상한 표현 금지 | ALL_L3 가 해결한 75과제 중 74과제를 30.6% 비용으로 해결했다 |
| 다른 모델에서도 재현되었다 | 방향 기준일 뿐 유의하지 않다 | 사전 정의한 방향성 기준은 충족했으나 유의하지 않았다 |
| 완전한 closed-loop 을 검증했다 | 경로 B 1/92 | 경로 B 는 92과제 중 1회만 쓰였다 |
| 우리 채점은 LLM 판정자보다 엄밀하다 | 비교 실험이 없다 | 판정 경로에 모델이 개입하지 않는다 |
