# 그림·표의 서사 지도 (Figure / Table Narrative Map) — 본문 아님

**작성 2026-08-20 · 그림·표는 LOCK 이다. 여기서는 «언제 어떻게 호출하는가»만 정한다**

🔒 F0~F4 · Main Table 1 · S1~S9 를 **수정하지 않는다.** caption 도 LOCK 이므로 본문이
caption 과 어긋나지 않게 쓴다(`figures/captions.md`).

**호출 순서가 곧 논문의 위계다.**

```
F0  연구 에이전트 A 의 구조        ← 첫 그림. τ 그림이 아니다

S1~S9  본문 주장을 뒷받침하되 서사를 가져가지 않는다
```

## 호출 규칙

1. **그림은 본문에서 처음 언급될 때 그 자리에서 설명한다.** 나중에 다시 부를 때는 수치를 반복하지 않는다.
2. **caption 이 이미 말한 것을 본문에서 그대로 되풀이하지 않는다.** 본문은 «왜 이 그림을 지금 보는가»를 말한다.
3. **본문의 강도가 caption 보다 세면 안 된다.** caption 은 LOCK 이라 고칠 수 없다.
4. **F0 → F1 → Main Table 1 → F2 → F3 → F4** 순서를 뒤집지 않는다. 이 순서가 곧 A → loop → 판단 문제 → τ → 결과의 위계다.
