# 한국어 과학논문 문체 calibration — 논문 본문 아님

**작성 2026-08-20 · 실제 사람이 쓴 한국어 학술 자료를 표본으로 관찰했다**

**목적** — 문법은 맞지만 한국 연구자가 실제로는 잘 고르지 않는 단어·어순·구조를 줄인다.
`paper/writing_rules.md` 의 anti-AI 규칙만으로 판단하지 않고, **실제 표본에서 관찰된 것**을
근거로 삼는다.

🔒 **표본의 문장이나 구절을 우리 논문에 옮기지 않는다.** 가져오는 것은 «한국어 학술문이
실제로 어떻게 움직이는가» 라는 calibration 뿐이다. 아래 인용은 **관찰 근거를 밝히기 위한
것**이며, 우리 본문에는 이 문장들이 들어가지 않는다.

**표기** 🟢 **OBSERVED**(표본에서 직접 관찰) · 🟡 **LIKELY_USEFUL**(표본과 어긋나지 않고
일반적으로 쓰이나 이 표본에서 충분히 확인되지 않음) · 🔴 **DO_NOT_GENERALIZE**(표본이
작아 규칙으로 삼지 않는다)

## 2. 관찰

### 2-1. 문장 종결형 🟢 OBSERVED

| 무엇을 말하는 문장인가 | 관찰된 종결 | 표본 |
|---|---|---|
| 배경·일반 사실 | **-이다 / -있다 / -한다** (현재형) | S1 «…역할을 한다», «…단점이 있다» |
| 우리가 수행한 일 | **-하였다** | S1 «합성하고 … 분석을 하였다», «측정하였다», «계산하였다» · S2 «제조하였고 … 만들었다» |
| 측정·관측 결과 | **-이었다 / -나타났다 / -나타내었다 / -되었다** | S2 «약 11.5 Å이었다», «…것으로 나타났다», «향상되었다», «약 90%의 사이클효율을 나타내었다» |

**calibration** — 배경은 현재형, 수행은 `-하였다`, 결과는 `-이었다 / 나타났다` 로 **층이
갈린다.** 한 논문 안에서 이 세 층을 뒤섞지 않는 것이 자연스럽다.
🔴 «했다/냈다»가 틀린 것은 아니지만, **표본 두 건 모두 `-하였다` 계열**이었다. 우리 논문도
`-하였다` 계열을 기본으로 두는 편이 표본과 어긋나지 않는다.

### 2-2. 능동·피동 🟢 OBSERVED

- **수행 동사는 능동이 지배적**이다(`합성하였다 · 측정하였다 · 제조하였다`).
- **결과 기술에는 자동사·피동형이 자연스럽게 쓰인다**(`나타났다 · 향상되었다 · 되었다`).
- 즉 «피동을 쓰지 마라»가 아니라 **«수행은 능동, 결과는 자동사/피동»** 이 실제 모습이다.

### 2-3. 주어 처리 🟢 OBSERVED — 가장 강한 관찰

**S1·S2 초록 전체에서 «우리는»·«저자들은» 이 한 번도 나오지 않는다.**
행위 주어는 전부 생략되고, 문장의 주어 자리에는 **대상·측정량**이 온다
(`층간거리는 …`, `비용량은 …`).
연구 목적을 밝히는 자리에서만 **「본 연구에서는」이 한 번** 나온다(S1, 배경→목적 전환 지점).

**calibration** — 한국어 학술문의 기본값은 **주어 생략**이고, 필요할 때 「본 연구에서는」
하나를 쓴다. 「우리는」을 반복하는 글은 표본과 다르다.

### 2-4. 수치를 문장에 넣는 방식 🟢 OBSERVED

- **[대상은] … [수치]이었다** — «층간거리는 약 11.5 Å이었다» · «비용량은 200 mAh/g 이상이었으며»
- **조건절을 문장 앞에** 두고 결과를 뒤에 — «10 mA/g의 방전율로 얻은 …» ·
  «1.9 V에서 3.9 V 전위영역에서 31회의 연속 충방전 실험을 한 결과 …»
- **「약」으로 완충**하는 것이 흔하다 — «약 11.5 Å», «약 90%».

**calibration** — 수치는 **서술어 바로 앞**에 오는 것이 한국어에서 가장 자연스럽다.
`writing_rules.md` 의 «수치는 그것이 뒷받침하는 주장과 가까운 자리»와 정합한다.
🔴 **«숫자는 문장 끝»** 같은 영어식 위치 규칙은 이 표본으로 지지되지 않는다.

### 2-5. 영어 용어 병기 🟢 OBSERVED

| 유형 | 관찰된 방식 | 표본 |
|---|---|---|
| 한국어 개념어 + 영문 약어 괄호 | `분광분석(NMR, IR)` | S1 |
| 정식 영문명 + 약어 괄호 | `4,5-bis(azidomethyl)-(1-butyl)-1,2,3-triazole (1-DABTR)` | S1 |
| 널리 쓰이는 약어는 그대로 | `DOS, DOA, IDP, BTTN`, `Gaussian 09`, `xerogel`, `vanadyl기` | S1·S2 |
| 영문 정식명 + 한국어 + 약어 | `유기발광다이오드 (organic light emitting diodes, OLED)` | S4 |

**calibration** — **한국어 개념어를 앞에 두고 괄호에 영문·약어**가 기본형. 화합물명·소프트웨어
이름·확립된 약어는 영문 그대로 둔다. 이는 `figures/captions.md`(LOCK)의 원어 유지 목록과
같은 방향이다.

### 2-6. 괄호 사용 🟢 OBSERVED

괄호는 **약어 정의와 기법 나열**에만 쓰인다. **부연 설명 문장을 괄호에 넣은 사례가 없다.**

### 2-7. 연결 표현 🟢 OBSERVED

관찰된 것은 **짧고 흔한 접속부사**뿐이다 — `특히` · `그러나` · `또한,` · `그리고` · `또한`.
🟢 **표본에 없었던 것** — `이를 통해` · `이러한 관점에서` · `맥락에서` · `시사한다` ·
`중요한 시사점을 제공한다`. (🔴 표본이 작으므로 «한국 논문에서는 절대 안 쓴다»고 단정하지
않는다. 다만 **우리가 기본값으로 삼을 이유도 없다.**)

### 2-8. 결과와 해석의 연결 🟡 LIKELY_USEFUL

- **근거를 문장 앞에, 해석을 완충 표지로** — «IR 스펙트럼에 의하면 … 결합하고 있는 것으로
  나타났다»(S2). 즉 한국어에서는 **근거 + 해석을 한 문장에 담되 `-것으로 나타났다` 로
  강도를 낮추는** 방식이 자연스럽다.
- 조건 + 결과를 한 문장에 — «… 실험을 한 결과 약 90%의 사이클효율을 나타내었다»(S2).
- 🔴 `-으로 판단된다` · `-으로 보인다` 는 흔한 표현이지만 **이 표본에서 확인되지 않았다.**

### 2-9. 초록의 전개 순서 🟢 OBSERVED (S1)

```
배경(무엇이 쓰이는가) → 대표 사례 → 문제·단점 → 「본 연구에서는」 목적과 수행
→ 「또한,」 추가 분석 → 「그리고」 마지막 항목
```
**«이 연구의 의의는 …» 같은 자평 문장이 없다.** 한 일을 나열하고 끝난다.

### 2-10. 표본에 나타나지 않은 AI 선호 표현 🔴 DO_NOT_GENERALIZE

`이를 통해` · `이러한` · `해당` · `가능하게 한다` · `제공한다` · `시사한다` ·
`관점에서` · `맥락에서` · `주목할 만하다` · `~에 대한 검증을 수행하였다`
→ 표본 5건에서 **관찰되지 않았다.** 표본이 작으므로 금지 근거로 삼지 않고,
`writing_rules.md` §4-1 의 판정법(«지웠을 때 뜻이 그대로면 필요 없던 말») 을 그대로 쓴다.

## 3. 우리 논문에 적용할 calibration (요약)

1. **주어 생략을 기본값으로.** 「본 연구에서는」은 목적을 밝히는 자리에 한 번.
2. **종결형을 층으로 나눈다** — 배경 현재형 / 수행 `-하였다` / 결과 `-이었다·나타났다`.
3. **수행은 능동, 결과는 자동사·피동**을 허용한다.
4. **수치는 서술어 바로 앞**, 실험 조건은 문장 앞.
5. **한국어 개념어 + (영문 약어)** 를 기본형으로, 원어 유지 목록은 LOCK 을 따른다.
6. **괄호는 약어·기법 정의에만.**
7. **접속은 짧게** — 특히 · 그러나 · 또한 · 그리고.
8. **자평 문장을 붙이지 않는다.** 문단 끝마다 교훈을 다는 습관을 버린다.

## 4. ✅ CALIBRATION_CONFLICT — **3건 모두 RESOLVED** (2026-08-20 사용자 결정)

세 건 모두 사용자가 결정했고 `paper/writing_rules.md` 에 반영했다.

### CONFLICT-1 · 「우리는」의 지위 — ✅ **RESOLVED**

- **관찰** — S1·S2 초록에서 「우리는」은 **0회**, 「본 연구에서는」은 1회.
- **최종 결정** — **주어 생략이 기본값이다.** 「본 연구에서는」은 **연구 목적·설계로
  전환하는 위치**처럼 행위 주체를 밝히는 것이 자연스러울 때 제한적으로 쓰고,
  「우리는」은 **다른 연구·조건과 행위 주체를 대비해야 할 때만** 쓴다.
  **둘 다 반복하지 않는다.** → `writing_rules.md` §3 주어 · §4-2 에 반영됨

### CONFLICT-2 · 관측과 해석의 분리 강도 — ✅ **RESOLVED**

- **관찰** — S2 는 근거 + 해석을 한 문장에 담고 `-것으로 나타났다` 로 강도를 낮춘다.
- **최종 결정 — 구간을 나눈다.**
  - **분리 강제** — 주요 결과 · null 결과 · 사후 검정 결과 · 인과 해석
  - **결합 허용** — 단순 기술 결과와 비핵심 서술에서, 강도가 섞이지 않고 한국어가
    자연스러워지는 경우(근거를 앞세우고 해석을 완충 표지로 낮추는 한 문장)
  - 🔒 **자연스러움을 이유로 null·사후 결과의 주장 경계를 흐리지 않는다.**
  → `writing_rules.md` §3 «관측과 해석» 에 반영됨

### CONFLICT-3 · 「수행하였다」의 금지 여부 — ✅ **RESOLVED**

- **최종 결정** — **금지 표현 목록에서 `수행하였다` 를 제거한다.** 다만
  ① 더 직접적인 동사가 자연스러우면 그쪽을 쓴다(`검증을 수행하였다` → `검증하였다`,
  `비교를 수행하였다` → `비교하였다`) ② `~의 수행을 수행하였다` 류 **이중 명사화는 계속
  금지** ③ `수행하였다` 의 **반복은 human-prose audit 대상**으로 남긴다.
  → `writing_rules.md` §4-1 · §4-2 에 반영됨

## 5. Human-Prose Preflight 점검 (집필 중 사용)

`writing_rules.md` §4 와 함께 쓴다. **기계적 치환을 금지한다.**

- [ ] 「우리는」이 반복되지 않는가 (주어 생략이 기본인가)
- [ ] 종결형이 배경/수행/결과 층에서 흔들리지 않는가
- [ ] 수치가 서술어에서 멀리 떨어져 있지 않은가
- [ ] 괄호에 문장을 넣지 않았는가
- [ ] 문단 끝마다 교훈을 붙이지 않았는가
- [ ] 금지어를 피하려고 **더 어색한 동의어**를 쓰지 않았는가 (그럴 땐 문장을 다시 쓴다)
- [ ] 전공자가 읽었을 때 «문법은 맞는데 왜 이 단어를 골랐지?» 라는 느낌이 없는가
