# 논문 설계도 (Manuscript Blueprint) — 문단 단위 · 본문 아님

**작성 2026-08-20 · prose 를 쓰지 않는다. 각 문단이 «무엇을 하는가»만 정한다**

**가제** 「계산하는 AI에서 판단하는 AI로: 실제 계산화학 도구를 이용한 자율 화학 가설 검증」
**시스템 호칭** 별도 이름을 만들지 않는다. 본문에서는 필요할 때 **「연구 에이전트 A」**.

**정본** 논리·경계 = `paper_logic/paper_fol_10.md` (commit `da096e6`) ·
집필 규칙 = `paper/writing_rules.md` · 문체 = `paper/korean_scientific_prose_calibration.md`

**위계** ① 연구 에이전트 A → ② scientific loop → ③ 증거 충분성 판단 문제 →
④ 방법 오차 grounding τ → ⑤ 조건·벤치마크 → ⑥ 통계. **τ 가 주인공이 되면 실패다.**

**읽는 법** — `O` 관측 · `I` 해석 · `B` 배경/정의.
claim strength 등급은 `paper/claim_language_matrix.md` 의 이름을 그대로 쓴다.
