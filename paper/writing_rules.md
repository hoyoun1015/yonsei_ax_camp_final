## 1. 논리 순서 — Paper-FOL 을 절에 배치한다

**기본 배치 (국문 관례)** — 서론 · 방법 · 결과 · 논의.
앵커는 Methods 를 맨 뒤에 두지만(Nature 형식) **투고처가 정해지기 전까지 채택하지 않는다**
(`writing_skill_audit.md` C1). **논리 순서는 절 배치와 독립이므로 지금 집필을 막지 않는다.**

| 절 | Paper-FOL | 그 절이 하는 일 |
|---|---|---|
| **서론** 1문단 | 1 | 결과만으로 추론의 질을 보장할 수 없다 |
| 서론 2문단 | 2 | 그렇다면 증거가 결론을 정당화하는지 봐야 한다 |
| 서론 3문단 | 3 | 그 판정도 모델·프롬프트 선택에 의존할 수 있다 |
| 서론 4문단 | 4 | 평가만으로는 원인을 바꿀 수 없다 → **통제된 개입 → A 를 만든다** |
| 서론 마지막 문단 | — | **연구 소개** — 무엇을 했고 무엇이 나왔는지 방향만 (숫자는 결과 절로) |
| **방법** | 5 | A 가 풀어야 하는 판단 문제 · 결정권 4종 · 비용 사다리 |
| 방법 | 6 | τ 실측 → 채점 기준 유도 → **동결** (판정 도구의 신뢰성은 여기) |
| 방법 | 7 | 조건 4종(V · V−τ · R0 · ALL_L3) · 동일 92과제 paired · 통계 계획 |
| **결과** | 4 | 시스템이 실제로 수행했는가 (FAILED 0/92 · 식별 76/76) |
| 결과 | 8 | **주 지표 널을 먼저**, 그다음 실제로 갈린 축 |
| 결과 | 9 | 적응적 계산과 비용 |
| **논의** | 10 | 앵커 FOL-9(b) 조건화 + 범위 한정 3문장 |
| 논의 | — | 한계 (§6-4 배치 규칙) · 보조 검증(S9)은 한 문단 |

**서론 다섯 문단은 초기 blueprint 이지 규칙이 아니다.** Paper-FOL 흐름을 가장 자연스럽게
전달하는 것이 우선이고, 필요하면 4~6문단으로 조정한다.

🔒 **Paper-FOL 4 는 서론과 결과에 두 번 나온다.** 서론에서는 «왜 만들었는가», 결과에서는
«실제로 동작했는가»다. **같은 문장을 두 번 쓰지 않는다.**

## 2. 문단 규칙 — 실제로 반복할 세 가지만

| 패턴 | 형태 | 쓰는 곳 |
|---|---|---|
| **P1 선언 → 근거 → 확장** | 첫 문장이 판정, 다음이 수치, 마지막이 «어디까지 그런가» | 결과 각 절 |
| **P2 관측 문장 / 해석 문장 인접쌍** | 숫자 문장 바로 다음 문장이 뜻 | 결과 · 논의 |
| **P3 짧은 전환 문장** | 논지를 꺾어야 할 때 짧은 완결문 하나. **글자 수를 규칙으로 두지 않는다** | 필요한 곳에서만 |

**모든 문단을 틀에 맞추지 않는다.** 위 셋 말고는 자유롭게 쓴다.

**문단 하나를 쓸 때마다 확인**

1. **관측과 해석을 한 문장 안에 섞지 않았는가.** 같은 문단에 둘 다 있다면 관측 문장과 해석 문장이 구분되는가 (P2)
2. 첫 문장만 읽어도 이 문단이 무엇을 하는지 알 수 있는가
3. 경계 문구(§6)가 필요한 주장인가. 필요하면 **그 문단 안에** 넣는다
4. 금지 표현(§5)이 들어갔는가

## 3. 문장 규칙

| 규칙 | 내용 |
|---|---|
| **숫자 위치** | 수치는 **그것이 뒷받침하는 주장과 가까운 자리**에 둔다. 한국어에서 자연스러운 위치를 우선하며 «항상 문장 끝» 같은 위치 규칙은 두지 않는다 |
| **정의 방식** | 지표는 처음 나올 때 **독자가 바로 이해할 만큼 짧게** 정의한다. 목표는 «정의를 찾아 앞뒤로 왕복하지 않게 하는 것»이고, 쉼표 동격은 자연스러울 때만 쓴다 (영어 appositive 의 기계적 이식 금지) |
| **관측과 해석** | 한 문장에 섞지 않는다. 잰 것 한 문장, 뜻 한 문장 |
| **강도** | **직접 측정한 값 자체는 불필요하게 완충하지 않고 명확하게 쓴다.** 다만 그 값의 **의미·일반화·인과·사후 분석의 중요도**는 실험 설계와 증거 수준에 맞게 제한한다 (§6-3) |
| **인과** | 개입 실험(V vs V−τ)이 있는 곳에서만 인과어를 쓴다. 관측 비교에는 쓰지 않는다 |
| **태** | 능동을 기본으로 하되, 한국어에서 자연스러우면 주어를 생략한다 |
| **주어** | **행위자를 밝혀야 뜻이 분명할 때만** «우리는» 또는 «본 연구에서는» 을 쓴다. 그 밖에는 주어를 생략하거나 실험 조건·시스템·대상을 주어로 둔다 (§4-2) |
| **길이** | 대부분 한 문장 두 절 이내. 절이 셋이면 자른다 |
| **반복** | 핵심 수치를 초록·결과·논의에서 다시 쓸 수 있다. **횟수를 정해 두지 않되, 반복할 때마다 그 자리에서 실제 서술 기능이 있어야 한다** |
| **소제목** | 결과 소제목은 «…의 분석», «…의 결과» 처럼 **연구 행위만** 적기보다 그 절이 답하는 질문이나 주요 발견을 드러낸다. **서술문이 자연스러우면 서술문, 명사구가 자연스러우면 명사구** — 억지로 문장으로 만들지 않는다 |

> 소제목 예시(확정 아님) — 서술문 «τ 를 빼면 판단이 달라진다» · 명사구 «방법 오차 정보를
> 뺀 조건의 행동». **앵커의 형식을 복제하는 것이 아니라 기능만 가져온다.**
> 실제 소제목은 집필 시 정한다.

## 4. 한국어 문체 규칙

**목표는 쉬운 글이 아니라 «한국인 연구자가 직접 쓴 것 같은 정확한 학술문»이다.**
**AI 티가 나면 단어를 바꾸지 말고 문장을 다시 쓴다.** 동의어 치환은 해결이 아니다.

### 4-1. 기계적으로 반복하면 안 되는 표현

> 이를 통해 · 이러한 · 해당 · 가능하게 한다 · 제공한다 · 시사한다 · 관점에서 ·
> 맥락에서 · 주목할 만하다 · 중요한 시사점을 제공한다 · 살펴보고자 한다 ·
> 라고 할 수 있다 · 수행하였다 · 확인할 수 있었다

**판정법** — 지웠을 때 뜻이 그대로면 원래 필요 없던 말이다.

🔒 **금지어 목록 자체가 목적이 아니다.** 어떤 단어가 그 문맥에서 자연스럽고 정확하면
써도 된다. **줄여야 할 것은 단어가 아니라 번역투·추상명사 연쇄·불필요한 지시어·과장된
형용사·같은 문장 구조의 반복·한국 연구자가 잘 쓰지 않는 어휘 조합이다.**
⛔ **금지어를 피하려다 더 이상한 동의어를 쓰는 것을 금지한다.** 그럴 때는 문장을 다시 쓴다.

### 4-2. 구조 차원의 규칙

| 증상 | 대신 |
|---|---|
| 영어 어순 직역 («…하는 것은 …을 의미한다») | 주어를 앞에, 술어로 끝낸다 |
| 추상명사 («개선의 가능성을 제시한다») | 동사로 («개선할 수 있다») |
| 피동 남용 («…이 관측되었다») | 행위자가 분명해야 할 때는 능동으로. 한국어에서 자연스러우면 피동도 쓴다 |
| 한 문장에 절 셋 이상 | 두 문장으로 자른다 |
| 지시어 연쇄 («이러한 결과는 이를 통해») | 지시어를 명사로 되돌린다 |
| 음차 남용 («에스컬레이션을 수행한다») | 우리말로 풀되 §5 의 원어 목록만 남긴다 |
| «우리는 …했다» 반복 | 행위자를 밝혀야 할 때만 쓰고, 아니면 주어를 생략하거나 조건·시스템을 주어로 («V 와 V−τ 는 동일한 92개 과제에서 비교하였다») |
| «…의 수행을 수행하였다» 류 명사화 | 동사 하나로 («…를 수행하였다» → «…하였다») |

### 4-3. 고쳐 쓰기 예시

| ✗ | ✓ |
|---|---|
| 본 연구는 방법 오차 정보의 제공이 에이전트의 의사결정에 미치는 영향에 대한 검증을 수행하였다. | 방법 오차를 알려준 조건과 알려주지 않은 조건을 동일한 92개 과제에서 비교하였다. |
| V 조건에서 74과제가 근거가 충분한 결론으로 판정되었다. | V 는 92과제 중 74과제에서 근거가 충분한 결론을 냈다. (또는 «…결론에 도달하였다») |
| 이러한 결과는 이를 통해 τ 의 역할을 시사한다. | τ 를 뺀 조건은 같은 과제에서 54과제를 해결했다. 차이는 20과제다. |
| V 가 74/92 로 τ 가 판단 품질을 크게 개선했음을 보여준다. | V 는 74/92, V−τ 는 54/92 였다. **(다음 문장에서)** 방법 오차 정보를 뺀 쪽이 20과제 적게 해결했다. |
| τ 는 과대해석을 유의하게 억제하는 것으로 나타났다. | 사전에 정한 주 지표인 과대해석에서는 두 조건이 갈리지 않았다(0 대 3, p = 0.25). |
| 본 연구의 핵심적 기여는 …를 가능하게 하는 프레임워크를 제공한다는 점에 있다. | 우리가 만든 것은 …다. |

**종결형** — «했다/냈다»도 «하였다/나타났다»도 기본값으로 강제하지 않는다. 한 문서 안에서
톤이 흔들리지 않는 선에서 문맥에 맞게 고른다(비교하였다 · 계산하였다 · 나타났다 ·
확인하였다 · 판단을 보류하였다).

### 4-4. 자가 점검 세 문항

1. **문장에서 숫자를 지웠을 때 뜻이 남는가?** 남지 않으면 해석이 아니라 나열이다
2. **«이 · 이러한 · 해당»을 전부 지워도 읽히는가?** 읽히면 원래 없어야 할 말이다
3. **소리 내어 읽어 숨이 차는가?** 차면 절을 잘라야 한다

## 5. 표기 규약 — 흩어져 있던 것을 여기 모았다

출처: `figures/captions.md`(LOCK) · `paper_fol_10.md` §6 · `RESUME_HERE.md` · `new_fol.md`.
**원문 문서를 수정하지 않고 사본만 취합했다.**

### 5-1. 원어로 남기는 것

> GFN2-xTB · B3LYP-D3(BJ)/def2-TZVP · τ · ΔE · p · R0 · V−τ · ALL_L3 · Band A–D · PI

**이 목록 밖은 한국어로 적는다.** (`captions.md` 표기 규칙, LOCK)

### 5-2. 금지 → 대체 (통합본)

| 쓰지 않는다 | 대신 |
|---|---|
| Band C 에만 있다 · confined to band C | 통계적으로 검출된 이득이 Band C 에 집중됐다 |
| Band C 밖에는 차이가 없다 | 유의한 차이가 검출되지 않았다 |
| ALL_L3 = 이론적 상한 · 도달 가능한 상한 | 모든 과제를 L3 로 실행한 비교용 정책 (75/92) |
| «…% 성능» 같은 비율 표현 | 75과제 중 74과제를 30.6% 비용으로 |
| τ 가 과대해석을 (유의하게) 줄였다 | 사전에 정한 주 지표에서는 두 조건이 갈리지 않았다 (p = 0.25) |
| 앵커의 68% 를 0% 로 낮췄다 | construct 가 다르다 — 나란히 놓지 않는다 |
| 완전한 closed-loop 을 검증했다 | 경로 B 는 92과제 중 1회만 쓰였다 |
| 그러므로 단순 fidelity router 다 | 식별 · 수준 선택 · 검토 · 상향 · 결론은 실제로 수행됐다 |
| 식별 성능이 뛰어나다 | 오류 0건의 천장 효과라 분산이 없다 |
| tool-limited = 줄일 수 없는 오류 | 지금 쓴 도구·수준에서 판단만 고쳐서는 해결하기 어려웠다 |
| 선행 채점은 전부 outcome-only · 추론 평가 최초 | 다수가 결과 중심으로 채점해 왔다 |
| 우리는 LLM 을 쓰지 않는다 | 외부 평가·채점 경로에는 모델이 개입하지 않는다 (내부 증거 검토는 LLM) |
| 앵커에 대한 반례 · 앵커가 틀렸다 | 계산화학 환경에서의 조건화 |
| 스캐폴드 1.5% 와 우리 수치를 나란히 | 다른 종류의 증거임을 밝히고 각각 서술 |
| 다른 모델에서도 유의하게 재현됐다 | 방향성 기준은 충족했으나 유의하지 않았다 (p = 0.4531) |
| τ 효과가 모델 간에 일반화된다 | V−τ 를 복제하지 않았다 |
| 계산 도구를 쓰는 에이전트를 최초로 만들었다 | (쓰지 않는다) |
| branch A / branch B | 경로 A / 경로 B |
| Supplementary Material | 보충자료 |
| justified resolution (본문에서) | 근거가 충분한 결론 |

### 5-3. 고정 문구 — 이 표현 그대로 쓴다

- **비용** — *"ALL_L3 가 해결한 75과제 중 74과제를 30.6% 비용으로 해결했다."*
- **Band C** — *"통계적으로 검출된 성능 이득은 Band C 에 집중되었다."*
- **비-C** — *"유의한 차이가 검출되지 않았다."* («효과가 없다»가 아니다)
- **경로 B** — *"재조작화 능력은 이 벤치마크에서 실질적으로 검증되지 않았다."*
- **식별 챌린지** — *"사전 지정된 nontrivial candidate set 에서 식별 성능이 무작위 쌍
  선택보다 유의하게 높았다."*
- **cross-model replication** — *"사전 정의한 방향성 복제 기준은 충족되었다. Sonnet 4.6
  에서도 V 는 R0 보다 더 많은 근거 있는 결론을 냈다(21/30 vs 18/30). 다만 이 차이는
  통계적으로 유의하지 않았으며(exact McNemar p = 0.453), V−τ 조건을 재실행하지 않았으므로
  τ 효과 자체의 모델 간 일반화가 검증된 것은 아니다."*

### 5-4. 수치는 canonical 산출물에서만 인용한다

| 무엇 | 어디서 |
|---|---|
| N=92 지표 · 조건별 수 | `results/main_run_aggregate.json` · F2 · Main Table 1 |
| 검정(불일치 b:c · p) | S1 |
| τ · Band 경계 | `data/tasks/frozen_rules_v1.json` · F1 · S2 |

| 식별 | S6 |

🔒 **기억으로 숫자를 쓰지 않는다.** 본문에 넣은 모든 수치는 위 표의 출처와 대조한다.

## 6. 주장 강도 규칙

### 6-1. 단계별 경계는 Paper-FOL 이 정본이다

집필 중 각 문단이 대응하는 Paper-FOL 의 **Boundary 블록을 그때그때 확인한다.**
이 파일은 그 요약본이지 대체본이 아니다.

### 6-2. 🔒 주 지표 널(p = 0.25) 서술 절차 — **네 단계로 고정**

앵커에는 «저자의 예상이 빗나갔다»를 다루는 사례가 없다(`anchor_writing_analysis.md` §6).
그래서 이 절차는 우리가 정한다.

1. **주 지표 결과를 그 축을 다루는 첫 문단에 둔다.** 뒤로 미루지 않는다
2. **한 문장으로 사실만 말하고 변명하지 않는다.** 길게 해명할수록 숨기는 것처럼 읽힌다
3. **바로 다음 문단에서 실제로 갈린 축(근거가 충분한 결론 · 과도한 신중 · Band C)으로
   넘어간다.** 순서가 «예상 → 빗나감 → 그러나 다른 곳에서 갈렸다» 여야 한다
4. **왜 빗나갔는지는 논의로 미룬다.** 결과 절에서 해석하지 않는다

### 6-3. 강도 계단

**직접 측정값 · 사전 지정 비교 · 사후 분석 · 기술 통계 · 탐색적 결과 · 일반화는 서로 다른
claim strength 를 가진다.** 예 — *"Sonnet V 는 21/30 이었다"* 는 직접 기술할 수 있지만
*"다른 모델에서도 τ 효과가 재현되었다"* 는 금지된다.

| 증거 | 쓸 수 있는 강도 |
|---|---|
| **직접 측정값** (우리가 잰 수) | 완충 없이 그대로 («…는 21/30 이었다»). **의미 부여는 다음 문장으로** |
| 동일 과제 paired 비교 + 검정 있음 | «…였다» 단정 + 수치 · p 병기 (단 사전 지정 여부 표시) |
| 기술 통계만 | «…였다» 단정, **해석은 붙이지 않는다** |
| 사전 지정 없이 사후 검정 | «사후 분석이다» 표시 필수 |
| 검정 없음 · n 작음 | «탐색적», «검정하지 않았다» |
| 유의하지 않음 | «검출되지 않았다». **«차이가 없다» 금지** |
| 실험 자체가 없음 | 쓰지 않는다 |

🔒 **N=92 의 정확 McNemar 8건은 비교축만 사전 지정됐고 검정 목록은 사후다**
(`DECISION_LOG` 2026-08-16 (6)). 본문에서 이 구분을 반드시 적는다.

### 6-4. 한계 배치 — 하이브리드

앵커는 한계를 산문에 녹이지만 우리 한계는 양이 다르다(L1~L8 + 식별 제한 5개 +
범위 한정 3문장). **핵심 세 개는 논의 본문에, 나머지는 별도 한계 절**에 둔다.

**논의 본문에 넣을 셋** — ① 검출된 이득이 Band C 에 집중됐다 ② 단일 모델이며 V−τ 를
복제하지 않았다 ③ 사전등록 주 지표는 널이었다.

### 6-5. 승격 금지

- **cross-model replication(S9)은 한 문단.** 주 결과처럼 키우지 않는다
- **τ 는 4순위 장치다.** 절 제목·초록 첫 문장에 τ 를 주어로 세우지 않는다
- **비용 절감 단독을 주제로 올리지 않는다.** 품질과 함께 보고한다
