## 2. 우리가 바꾸는 «핵심 명제 하나» — 후보 3개

### 후보 A — 판정자 대체
> **앵커 FOL-5 를 바꾼다.** 인식적 정직성의 판정은 LLM 주석을 요구하지 않는다.
> 적어도 한 도메인에서는 **물리 방법오차에서 유도한 결정론적 기준**으로 대체할 수 있고,
> 판정 경로에 모델이 한 번도 개입하지 않는다.

**지지 증거** NEW-FOL-5·6·7 (τ 실측 · 채점 정의 · N=92 자동 생성) ·
NEW-FOL-9 (전량 무실패 동작) · 사전 동결 해시

**방어 가능성 평가 — 🟡 중간**
- 🟢 강점: 구성적으로 참이다. 채점 코드에 LLM 이 없다. 검증 가능하고 재현 가능하다.
- 🔴 **치명적 약점: 이 방향으로 판 지표가 정확히 널이었다.** 과대해석률 V 0 vs V−τ 3,
  **p = 0.25**. "우리 기준으로 재보니 차이가 보였다"를 이 축에서 말할 수 없다.
- 🔴 앵커의 68% 와 우리 0/92 는 **construct 가 다르다** — 앵커는 트레이스 내 증거
  채택 여부, 우리는 «자기 증거 대 τ» 단정 여부. 숫자를 나란히 두면 OVERCLAIM.
- 🟡 "대체 가능하다"는 **1도메인 · 1관측량 · 2수준**에서만 보였다.

→ **단독 헤드라인으로 세우기 어렵다.** 방법론 기여로는 유효하나, 이 축의
   실증 결과가 널이므로 "그래서 무엇이 달라졌나"에 답하지 못한다.

### 후보 B — 계산화학 환경에서의 **qualification / refinement** ★
> **앵커 FOL-9(b) 를 «부정»하지 않고 «조건화»한다.**
> 계산화학의 상대에너지 판정이라는 환경에서, **도메인의 방법오차를 명시적으로 알려주는
> 단일 스캐폴드 구성요소를 제거하면 3-agent 시스템의 판단 품질이 규칙 한 줄과
> 통계적으로 구분되지 않는 수준으로 내려간다.** 즉 이 환경에서는 그 구성요소가
> 관측된 이득의 대부분을 운반한다.

**🔒 표현 규칙 (2026-08-14 사용자 지시).**
- ❌ *"앵커에 대한 반례"* · *"앵커가 틀렸다"* → **쓰지 않는다**
- ✅ *"계산화학 환경에서의 qualification"* · *"조건을 특정한 정밀화"*
- ❌ **앵커의 «스캐폴드 1.5%» 와 우리 ablation 수치를 동종 비교하지 않는다.**
  앵커는 여러 스캐폴드에 대한 **분산 설명력**(관측 연구), 우리는 **단일 구성요소의
  개입 효과**(ablation). **측정 대상도 설계도 다르다.** 같은 표·같은 문장에 나란히
  놓지 않고, "다른 종류의 증거"임을 명시한 뒤 각각 서술한다.
- ✅ 안전한 형태 — *"앵커는 스캐폴드 일반의 평균 효과가 작다고 보고했다. 우리는 이와
  다른 설계(단일 구성요소 ablation)로, 한 도메인에서 특정 구성요소의 제거가 큰 차이를
  낳는 것을 관측했다. 두 결과는 서로 모순되지 않는다 — 평균이 작다는 것이 모든
  구성요소의 효과가 작다는 것을 함의하지 않는다."*

**지지 증거**
| | 수치 | 검정 |
|---|---|---|
| V vs V−τ | 74/92 vs 54/92 | 불일치 21:1 · **p = 1.1×10⁻⁵** |
| **V−τ vs R0** | **54/92 vs 56/92** | 불일치 15:17 · **p = 0.86 (구분 불가)** |
| V vs R0 | 74/92 vs 56/92 | 불일치 23:5 · **p = 9.1×10⁻⁴** |
| 밴드 C | 22 / 11 / 8 | V vs V−τ **p = 9.8×10⁻⁴** |
| 비용 | V 30.6% · **V−τ 139.3%** | — |

**방어 가능성 평가 — 🟢 가장 높음**
- 🟢 사전등록된 주 대비(V vs V−τ)이고 **결과를 보기 전에 동결**됐다.
- 🟢 paired 설계, 동일 92과제, 검정력이 실제로 나왔다 (p = 10⁻⁵ 수준).
- 🟢 **V−τ ≡ R0 (p=0.86)** 가 특히 강하다 — "정교한 구조를 만들어도 도메인 오차
  정보가 없으면 규칙 한 줄과 같다"는 진술은 **앵커의 방향과 정합적**이면서, 동시에
  «그 환경에서 어떤 구성요소는 다르다»를 보인다. **부정이 아니라 조건화다.**
- 🟢 비용이 반대 방향으로 붙는다 — V−τ 는 **더 비싸고(139.3%) 더 못한다.**
- 🟡 **주의 1:** 앵커의 1.5% 와 우리 수치는 **동종 비교가 불가능하다** (위 표현 규칙).
  나란히 쓰지 않는다.
- 🟡 **주의 2:** **검출된 이득이 밴드 C 에 집중**돼 있다 (비C 는 p=0.39 로 검출되지 않았다 —
  **효과가 0 이라는 증명은 아니다**). "일반적으로 성능을 운반한다"가
  아니라 **"escalation 이 값을 하는 구간에서 운반한다"**로 좁혀 써야 한다.
- 🟡 **주의 3:** 단일 모델. 복제 진행 중이고 **V−τ 는 복제 계획에 없다.**

## 3. 권고

**후보 B 를 핵심 명제로 삼는 것을 권고한다.**

이유 세 가지 —
1. **유일하게 잘 검정된 축이다.** p = 1.1×10⁻⁵ 와 p = 0.86 이 한 쌍으로 나온다.
2. **사전등록된 주 대비 그대로다.** post-hoc 프레임 선택이 아니다.
3. **앵커를 부정하지 않고 조건화한다** — 심사자에게 방어하기 가장 쉬운 형태다.
   "앵커가 틀렸다"가 아니라 "이 환경에서는 이렇게 좁혀진다"이므로, 앵커의 대규모
   증거(25,000 실행)와 정면 충돌하지 않는다.

**단, 후보 B 를 쓸 때 반드시 함께 적어야 하는 세 문장** —
- **검출된 이득은 밴드 C 에 집중**됐다 (밴드 C 제외 시 p = 0.39 — 검출되지 않았을 뿐
  효과가 0 이라는 뜻이 아니다). ⛔ «밴드 C 에만 있다 / confined to band C» 금지.
- **단일 모델**이며 V−τ ablation 은 복제 계획에 없다.
- 사전등록 **주 지표는 널**이었다 (과대해석 p = 0.25). 우리가 관측한 것은
  «과대해석 감소»가 아니라 «근거 있는 해결의 증가와 과도한 신중의 감소»다.

**후보 A 는 «방법 기여»로 방법 절에 둔다.** 헤드라인으로 올리지 않는다 — 그 축의
실증 결과가 널이기 때문이다. `CLAUDE.md` 위계(주인공은 에이전트, τ 는 3순위 장치)와도
일치한다.

⚠️ **사전등록 프레임 규칙과의 정합성 확인.** `기획안_v3.md` §13 은 결과 갈래를 미리
정해뒀다 — *"갈래 2 대등한 경우: 계산은 수행하지만 그 계산의 한계 인식은 규칙 이상으로
나아가지 못한다"*. **실제 결과는 갈래 1(판단 품질이 기준선을 넘음)에 해당한다**
(V 74 vs R0 56, p=9.1×10⁻⁴). 따라서 후보 B 는 **사전등록된 갈래 1 프레임**이며
결과를 보고 새로 만든 프레임이 아니다.

## 6. StatefulDiscovery (arXiv 2606.11851) — 본문 확인 결과 (2026-08-14)

가장 가까운 경쟁 연구다. **§3.2–3.3 · §4.2 · Appendix D 를 직접 확인**했다.

### 확인된 사실 (인용 가능한 형태)

**초록.** *"Across multiple rounds of exploration, a discovery agent must decide which
phenomena warrant investigation while avoiding **overinterpretation, where emerging
claims exceed the evidential scope of the analyses supporting them**."*
→ **overinterpretation 의 정의가 우리와 사실상 같다.**

**2층 구조.** L1 = global frontier-control (무엇을 다음에 조사할지) ·
**L2 = local hypothesis-set adjudication** (증거 평가와 주장 보정).

**L2 내부 판정.** *"At the local level, the agent uses L2 adjudication to evaluate
evidence for the active investigation."* — **`evidence-strength-judge` 라는 LLM skill**
이 수행하며, 가설마다 `supported / weakened / refuted / inconclusive` 중 하나를 부여한다.
그 skill 은 *"reads the active hypothesis set, query bundle, and executed evidence, and
writes hypothesis outcomes, investigation confidence, red flags, resolution status,
recommendations for next steps, surprise signals, and finalizable claims."*
⚠️ **§3.2–3.3 에서 이 skill 의 백본 모델명은 명시되지 않는다.**

**최종 평가 지표 (§4.2).** 두 지표를 분리한다.
- **ES (Evidential Support)** — *"measures whether the executed analysis output
  justifies a claim"*
- **DV (Discovery Value)** — *"measures whether the claim adds nontrivial explanatory
  or structural understanding beyond a uniform first-pass analysis"*
- 둘 다 **1–5 rubric 기반 LLM judging** —
  `s^ES_ij = LLM(ρ_ES; d_i, c_ij, e_ij)` · `s^DV_ij = LLM(ρ_DV; d_i, c_ij, f_i)`
- **HQ** = ES ≥ 4 **and** DV ≥ 4

**판정 모델.** *"All LLM-based judges use **Gemini-3.1-pro**, with prompt templates
provided in Appendix D."* 방법 간 비교는 **position-swapped pairwise judging**
(불일치는 무승부 처리).

**인간 검증.** PhD 급 주석자 2인(통계·생물, 소속 다름)이 **층화 표본 120 claim** 을
같은 1–5 rubric 으로 독립 채점. within-one agreement · MAE · 순위상관을 보고하며
자동 judge 가 *"shows reasonable consistency with expert annotations"*.
**즉 전면 평가는 자동 LLM judge 이고 인간은 spot-check 이다.**

### 우리 방식과의 차이 — **과장 없이**

| 축 | StatefulDiscovery | 본 연구 |
|---|---|---|
| 에이전트 **내부** 증거 판정 | LLM skill `evidence-strength-judge` | **LLM (Skeptical Reviewer)** |
| **채점(평가)** | **LLM judge (Gemini-3.1-pro) · 1–5 rubric** + 인간 120건 spot-check | **결정론적 함수** — `\|ΔE_calc\| vs τ(M_used)` · `\|ΔE_ref\| vs τ 사다리`. **모델 없음** |
| 채점의 재현성 | 프롬프트·모델·샘플링에 의존 | 같은 입력 → 같은 출력 (순수 함수) |
| 채점 기준의 출처 | rubric (사람이 쓴 텍스트) → LLM 해석 | **GMTKN55 참조값 대비 실측 MAE** |
| 무엇을 재는가 | ES(증거 정당성) + **DV(발견 가치)** | 증거 정당성 계열만. **DV 대응물 없음** |

**🔒 정확히 이렇게만 쓴다.**
- ✅ *"우리 차별점은 **채점 축**에 있다 — 판정 경로에 모델이 개입하지 않는다."*
- ⛔ *"우리는 LLM 을 쓰지 않는다"* → **거짓.** 우리 에이전트도 3개 역할 전부 LLM 이고,
  Skeptical Reviewer 는 저들의 L2 skill 과 **같은 종류의 구성요소**다.
  **내부 판정 축에서는 차별점이 없다.**
- ⛔ *"우리 방식이 더 낫다"* → 비교 실험을 하지 않았다. **다른 도메인 · 다른 지표**다.
- 🟡 **DV 는 우리에게 대응물이 없다.** 저들은 «발견의 가치»까지 재고, 우리는 «판정이
  자기 증거에 정당한가»만 잰다. **범위가 다르다는 것을 명시해야 한다** — 우리 채점이
  더 좁은 것을 «더 엄밀하다»로 포장하면 OVERCLAIM.
- 🟡 저들의 백본 모델명이 §3.2–3.3 에 없으므로, **«내부 판정도 Gemini-3.1-pro 다»
  라고 단정하지 않는다.** 확인된 것은 **judge 가 Gemini-3.1-pro** 라는 것뿐이다.

### 이것이 후보 A 에 주는 함의

후보 A(판정자 대체)의 주장 범위가 **좁아진다** — 우리가 대체한 것은
**«평가자로서의 LLM»** 이지 «에이전트 내부의 LLM» 이 아니다.
앵커(2604.18805)도 StatefulDiscovery 도 **평가에 LLM 을 쓴다**는 점에서 같고,
우리는 그 자리에만 결정론적 기준을 넣었다. **이 한정이 논문에 명시돼야 한다.**
