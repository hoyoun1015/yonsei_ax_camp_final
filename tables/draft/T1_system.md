# 표 1 — 두 조건의 실행 동작

**caption 초안**

> **표 1. 두 조건의 실행 동작.** 같은 92과제를 조건 V 와 V−τ 로 각각 실행한 결과다. 두 조건 모두 모든 과제를 끝까지 수행했고, 자율 식별 정확도도 76/76으로 같았다. 실행 과정에서는 계산 수준 선택과 반복 계산 패턴이 크게 달랐다. 근거가 충분한 결론은 식별 방식별로 나누어 함께 제시했으며, 전체 결과와 통계 검정은 그림 3에 제시한다.


**표**

| 지표 | V | V−τ |
|---|---:|---:|
| 완료하지 못한 과제 (FAILED) | 0 / 92 | 0 / 92 |
| 자율 식별 정확도 | 76 / 76 | 76 / 76 |
| — 자율 식별형의 근거가 충분한 결론 | 63 / 76 | 46 / 76 |
| — 쌍 지정형의 근거가 충분한 결론 | 11 / 16 | 8 / 16 |
| 최종 판단 수준이 L3인 과제 | 45 / 92 | 91 / 92 |
| L3 실행 횟수 | 45 | 101 |
| 경로 A (계산 수준 상향) 사용 횟수 | 45 | 22 |
| 경로 B (비교 대상 재설정) 사용 횟수 | 1 | 11 |
| 라운드 분포 (1 / 2 / 3) | 46 / 46 / 0 | 66 / 19 / 7 |

**각주**

a. 유효 본실행은 3개 묶음, 총 **911회 호출**(약 221분)이다. 첫 시도에서 구조화된 출력을 얻지 못한 호출이 **5회** 있었고 모두 재시도 경로에서 복구됐다. 그중 **1회**는 실행 도구가 오류 상태를 반환한 경우(일시적 네트워크 오류)이고, 나머지 **4회**는 정상 상태로 응답했으나 본문이 비어 있던 경우다 — 즉 오류 상태 1회는 구조화 출력 실패 5회에 **포함된다**. 원장 파일(JSONL)의 줄 파싱 실패는 **0**, 과제 단위로 실패한 과제는 **0** 이다.

b. 자율 식별 정확도의 분모에서 쌍 지정형 과제는 제외했다. 그 과제들은 비교할 두 구조를 지정받으므로 식별을 수행하지 않는다. 두 조건 모두 분모와 분자가 같아 이 지표에는 조건 간 차이가 남아 있지 않다.

c. 경로 A는 계산 수준을 올린 횟수, 경로 B는 원래 가설을 그대로 둔 채 비교 대상만 다시 정한 횟수다. **「최종 판단 수준이 L3인 과제」는 마지막 판단을 L3 결과로 내린 과제를 세며, L3 계산이 한 번이라도 돌아간 과제와 다르다.** 조건 V−τ에서는 L3가 한 번이라도 돌아간 과제가 92개인데 최종 판단 수준이 L3인 과제는 91개다 — 한 과제는 L3로 계산한 뒤 비교 대상을 다시 정해(경로 B) 마지막에는 L1 결과로 판단을 마쳤다. 조건 V에서는 두 수가 모두 45개로 같다. L3 실행 횟수가 과제 수보다 큰 것은 같은 과제를 두 번 이상 계산한 경우가 있기 때문이다.

d. 전체 근거가 충분한 결론·p값·계산 비용 %는 그림 3·4에 있으므로 이 표에서 반복하지 않는다.

**표에 넣지 않은 계획 지표**

- `hypothesis_fidelity` — §7.2가 규정한 «원 가설 유지의 결정론적 검사»가 구현되지 않았다. 구현은 필드가 비었는지만 보므로 보고하지 않는다 (DECISION_LOG 2026-08-16 (1)).
- `protocol_validity` — 실행 명세가 미리 계산된 registry 안(계산 수준 2택 × 후보 구조 쌍)에서만 만들어지므로 100%가 구성상 보장된다. 성과 지표로 쓰지 않고 Methods 각주로만 밝힌다.
